4. NOT SHIPPED: USED AS A REFERENCE OR CALLED ON THE USER'S SYSTEM
------------------------------------------------------------------

AMD Display Library (ADL) SDK
  Licence:   MIT (notice in include/adl_sdk.h)
  Text:      ADL/LICENSE.txt
  Source:    https://github.com/GPUOpen-LibrariesAndSDKs/display-library
  Use:       read-only GPU tuning data. Nexum declares 11 ADL functions by hand (set-up,
             tear-down and "Get"/"Caps" reads only) and calls the atiadlxx.dll that the
             AMD graphics driver installs in System32.
             No ADL file is shipped and no ADL "Set" function is ever called.

ZenStates-Core
  Licence:   GPL-3.0 (same as Nexum; text in LICENSE)
  Notice:    ZenStates-Core/NOTICE.txt
  Source:    https://github.com/irusanov/ZenStates-Core
  Use:       the DDR4 memory-controller register map (Dictionaries/DDR4Dictionary.cs)
             that nexum-agent/Spec/MemoryTimings.cs follows to read live DDR4 timings.

PawnIO (kernel driver)
  Not included, not redistributed, not installed by Nexum. Installed separately by
  the user from https://pawnio.eu/ (source: https://github.com/namazso/PawnIO.Setup).

Microsoft Edge WebView2 Runtime
  Not included. Part of Windows 11; the installer downloads Microsoft's bootstrapper
  when it is missing.
